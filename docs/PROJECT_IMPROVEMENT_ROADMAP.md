# Superseded Improvement Roadmap

This document previously proposed feature and benchmark work that allowed a
benchmark script to mark its own result as verified. That process is no longer
valid and the old roadmap is retained only through Git history.

The active plans are:

* [Project Roadmap](../ROADMAP.md) for engineering milestones;
* [Research Protocol](RESEARCH_PROTOCOL.md) for the frozen experiment design;
* [Artifact Evaluation Guide](../paper/ARTIFACT_EVALUATION.md) for execution
  and independent reproduction;
* [Current Evidence Status](CURRENT_EVIDENCE_STATUS.md) for claim eligibility.

Current priorities are core correctness, bounded overload behavior,
process-crash durability, reproducible evidence, and negative-result reporting.
Hybrid routing, adaptive memory, sessions, permission filtering, and Redis
remain separate experimental work until each has its own protocol and tests.
